How should we handle the noise?

Three directions for making 50 Hz motor telemetry readable. Pick what resonates — or mix and match.

A

Rolling Average Smoothing

Apply a 1–2 second sliding window mean before plotting. Raw data shown faintly in background. Keeps the familiar line-chart structure but removes the high-frequency noise.

Pros

  • Minimal code change
  • Familiar format
  • Window is tunable

Cons

  • Still cluttered with many motors
  • Misses peak spikes
B

Heatmap (Time × Motor)

Replace per-motor line charts with a 2D color grid. X = time, Y = motor ID, color intensity = power level. Instantly shows which motors were hot and when, without any line clutter.

Pros

  • Scales to many motors
  • Pattern recognition at a glance
  • Zero line clutter

Cons

  • Loses absolute values
  • seaborn dependency
C

Percentile Band (Median ± IQR)

For each time window, plot the median as a line and shade the 25th–75th percentile range as a band. Peaks marked separately. Ideal for cross-match comparison — overlay bands per match instead of noisy traces.

Pros

  • Best for cross-match comparison
  • Shows variability, not just mean
  • Clean even with many motors

Cons

  • More complex to compute
  • Requires binning time axis
