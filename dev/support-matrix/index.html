Support matrix and known limits¶

What Flashpoint works with, and how we know. Every "supported" cell names its evidence: a group of the public log corpus that the test suite runs on, a test, or a dated check on an outside team's logs. The corpus is Ignite's own 2025 and 2026 robots, so anything Ignite's robots don't have reads "not tested" until someone's logs show it working.

Value Means
supported Tested on real logs; the evidence is named
supported (needs Phoenix Pro) The same, but only with a Phoenix Pro license on the device
rough Works end to end with a workaround, named with its issue
not tested on real logs Only synthetic test data covers it
not tested Nobody has checked it yet. It may well work: tell us
not supported Doesn't work; the linked issue tracks it

The tables are generated from support-matrix.toml.

Known limits¶

The 2027 season and Systemcore¶

This version ships a 2027 season file, so doctor stays green after January 1. But 2027 hoots will need a newer owlet than this version knows, and Live CAN's NetworkTables library is held below its 2027 release. Both come in Flashpoint 0.3.1, planned for kickoff week (2027-01-16): update then (Start a new season). Systemcore, the 2027 control system, is untested (#110). Season tracking: #73.

The first hoot needs internet¶

Flashpoint converts hoots with CTRE's owlet, which it downloads the first time it meets a hoot version and then keeps. A pit laptop that has never read a hoot can't read one offline. Ingest one hoot at home before the event, or install offline with owlet included. flashpoint doctor checks that the owlet for each hoot format in your lake is cached.

Hoots without a wpilog¶

A session with hoots but no wpilog gets no motor history: no Replay tracks, usage or match features. Ingest warns session(s) with hoots but no wpilog, and when every session of a season is like that, doctor's "Hoots without a wpilog" check warns too. One such session among many is usually the hoot logger restarting mid-event, and is safe to ignore. The fix is on the robot: turn on the WPILib DataLog. Hoot-only sessions are also missing from motor usage totals (#8).

Beta and experimental features¶

Feature Label Why
Robot pull (automatic import from the robot) beta, tested on one robot Run on Ignite's robot only so far (#74). USB import has no label
Anomalies beta Thresholds are tuned on one team's logs; expect findings to need judgement (#77)
Live CAN experimental Needs robot code, and a fast bus can show false dropouts

Known issues¶

  • Linux owlet can crash on power-loss-truncated hoots. On Linux, CTRE's owlet sometimes exits with an error on a hoot whose tail was cut off by a power loss (macOS doesn't). Flashpoint retries the conversion, so the file usually still imports with incomplete-read. If a hoot stays failed (owlet-failed), run flashpoint rebuild once. History: #4 (closed), tracked end to end in #71.
  • A relative --lake path crashes detect. Give --lake an absolute path (--lake "$PWD/lake"). ingest still exits 0 in that case, with no Replay data (#107).
