Before, during and after every match.

Clickable prototype of the Flashpoint telemetry UI. Runs locally with no build step and no server. All data is simulated for one demo robot whose problems show up consistently across every screen. Press Ctrl K anywhere to jump to a mechanism, device, match or anomaly.

Live

Watch a match as it happens: vitals, every mechanism, events, alerts.
Replay

Scrub a match log, jump to faults, see likely causes and fixes.
Pit

Pre-match go/no-go: devices, faults, firmware, battery.
History

Every device across seasons, tracked by serial number, not robot slot.
Anomalies

Devices running outside spec, with evidence, causes and past cases.

Specs live in /docs. Start with README.md at the package root.
